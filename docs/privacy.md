# 隐私与数据

独立桌面版固定使用 ~/Library/Application Support/HapticBridge/studio.json。CLI 可用 HB_STUDIO_FILE 指定绝对路径；未指定时保留源码开发模式 .local/studio.json。控制权、启用状态、播放状态与会话不会落盘。

程序服务绑定 127.0.0.1。公开源码不包含用户数据库、凭据、真实原稿、模型权重或历史成功报告。不要把私人目录、.env、访问文件、带真实资料的导出件或完整诊断日志上传为 Issue。对外反馈先换成合成样例，只提供版本、错误代号和最小复现步骤。

本地运行不等于所有进阶服务都离线：只有你显式配置/调用的外部模型、仓库检查、设备适配或远程基础设施才涉及对应目标。使用前阅读配置和权限；不会为获得演示结果自动购买服务。

备份时正常退出并确认任务停止，使用系统加密备份保存完整私人目录。保留原件和最近成功备份，恢复到新目录核对；不要覆盖唯一原件。
