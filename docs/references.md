# 设计参考与许可

[Meta Haptics Studio](https://github.com/meta/haptics-studio)：借鉴时间包络与可导出模式的思路；[Intiface Central](https://github.com/intiface/intiface-central)：参考显式连接与设备能力显示。未复制或捆绑其应用。

借鉴的是交互与工作流；没有复制未审阅许可的代码、品牌素材或模型。本仓库新增用户交付与界面代码遵循根许可证；第三方来源保留单独署名与许可。UI 使用克制的层级、触手可及的操作、清晰的空/错/进行状态，以及各产品自己的配色。避免装饰性发光和没有业务意义的生成文案。
