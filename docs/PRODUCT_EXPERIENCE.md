# 模式编辑与播放

先调每一步的强度和时长，再保存或预览整个模式。虚拟设备用于演练播放、取消与停止；真实设备需要单独连接。

## 工作台

Studio展示全部最多120条会话记录，支持设备/动作筛选和脱敏JSON导出。320px步骤编辑拆成两行、操作目标44px；可选品牌资料折叠；标题改为具体任务。

## 数据、异常与资源边界

仅固定虚拟设备。历史、连接/arming、播放不持久化；保存模式和设置维持原0600文件与并发控制。未连接真实设备，不新增硬件adapter。

## 历次验证

类型/构建、64项本机软件检查、29场景Studio浏览器回归、资源检查、桌面/390px/320px新增筛选导出。关闭后计时器/播放均为0；短采样不代表长期无增长。

## 本地启动

```sh
npm ci && npm run studio
# Node24，默认127.0.0.1:18766；需要主动获取本地控制权。
```


托管检查补齐：偏好保存期间，新建/载入/复制和添加步骤遵守忙碌状态，避免新模式读取尚未确认的旧默认值。定向回归延迟真实保存响应，确认编辑操作锁定，等待真实落盘回执后再核对新步骤的33%/0.7秒；原断言保持。
